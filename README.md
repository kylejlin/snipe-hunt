# Snipe Hunt

Snipe Hunt is a two-player card game.
The current implementation is in [`rust-impl`](./rust_impl/).
There are also two older (deprecated) implementations:

- A JavaFX implementation
- A Create-React-App (TypeScript) implementation

There may be bugs.

## Rules

The JavaFX implementation contains a [user guide](./older_impls/java_impl/Snipe%20Hunt%20JavaFX%20Guide.pdf), which includes a rulebook.
